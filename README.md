# Archiv — Downloads

Hier liegen die fertigen Versionen von **Archiv** für Windows und den Mac.

**Neueste Version:** [Releases → Latest](https://github.com/BorisBorisson/archiv-releases/releases/latest)

- **Mac** (Apple Silicon, macOS 14 oder neuer): `Archiv-macos-arm64.zip`
- **Windows** (64 Bit): `Archiv-windows-x64.zip`

Einmal installiert, hält sich Archiv von selbst aktuell.
