# Archiv — Downloads

Hier liegen die fertigen Versionen von **Archiv** für Windows und den Mac.

**Neueste Version:** [Releases → Latest](https://github.com/BorisBorisson/archiv-releases/releases/latest)

- **Windows** (64 Bit): `Archiv-Setup.exe` herunterladen und starten.
- **Mac** (Apple Silicon, macOS 14 oder neuer): `Archiv-macos-arm64.dmg` öffnen und
  Archiv auf „Programme“ ziehen.

Einmal installiert, hält sich Archiv von selbst aktuell. Die `.zip`-Dateien
braucht Archiv für seine Updates; zum Installieren sind die Installer gedacht.
